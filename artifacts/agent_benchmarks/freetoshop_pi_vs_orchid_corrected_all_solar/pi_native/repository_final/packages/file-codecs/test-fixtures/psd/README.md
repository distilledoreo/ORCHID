# PSD fixture corpus

These tiny deterministic files exercise the first read-only PSD boundary.
Regenerate them with:

```sh
node packages/file-codecs/scripts/generate-psd-fixtures.mjs
```

| Fixture                         | Purpose                                                                |
| ------------------------------- | ---------------------------------------------------------------------- |
| `flattened-rgb-8.psd`           | 8-bit RGB composite without layer records                              |
| `pixel-layers-rgb-8.psd`        | Layer order, cropped bounds, opacity, blend                            |
| `nested-group-rgb-8.psd`        | Nested group and pass-through structure                                |
| `truncated.psd`                 | Signature-only malformed-file rejection                                |
| `psb-header.psb`                | Explicit PSB version rejection                                         |
| `multi-alpha-raw-rgb-8.psd`     | 8×4 RGB + 2 raw composite alpha planes (synthetic multi-plane decode)  |
| `mask-effects-guides-rgb-8.psd` | 8×8 layered RGB + user mask + drop-shadow/stroke + guides (no injects) |
| `text-layer-rgb-8.psd`          | 16×8 text layer + background (no injects)                              |
| `smart-object-linked-rgb-8.psd` | 8×8 SO with linked nested PSD + preview (no injects)                   |
| `work-path-resource.psd`        | 100×80 minimal PSD image resource 2000 (Work Path)                     |

The files are generated by the pinned `ag-psd` dependency from original pixel
data and contain no third-party artwork. They are compatibility probes, not a
claim of broad PSD coverage.
