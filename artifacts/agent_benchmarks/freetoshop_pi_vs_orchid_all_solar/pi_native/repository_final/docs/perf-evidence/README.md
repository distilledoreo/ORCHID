# Browser and Node composite performance evidence

This directory stores reproducible evidence for the M2 composite tile cache.

## Commands

```bash
# Node warm/cold composite benchmarks (CI guardrails)
npm run benchmark

# Chromium browser probe + live canvas diagnostics
npm run test:browser-perf

# Chromium + Firefox + WebKit composite performance suite
npm run test:browser-perf:all
```

## Acceptance bars used by the suite

- Warm median must be faster than cold median in the browser probe
- Warm median must be under 50 ms for the 256×256 / 8-layer fixture
- Probe must report `fullyWarm: true` after the warm samples
- Live canvas must populate composite-cache diagnostics after a deterministic blend recompose
- Live zoomed-out advanced composition must stream an exact smaller mip frame in all three engines without cross-mip reuse.
- Worker cold path: `warmOnlyReferenceCalls === 0` and `workerMatchesReference`
- Working set: `stayedWithinBudget` and `boundedGrowth` under configured `maxBytes`
- Long session: 120 revisions stay within `maxBytes` with `boundedGrowth`
- Live App long session: 120 real revisions stay within the 96 MiB production cache budget, second-half growth is bounded, the worker settles, and Chromium post-GC heap grows by less than 32 MiB
- Live App eviction: a full worker frame larger than the diagnostic cache is not chained/seeded; real pans and localized edits stay within budget, increase eviction count, and settle in Chromium, Firefox, and WebKit
- Large-doc interactive: 1024×1024 progressive warm viewport/pan/return-home under 50 ms; progressive first paint fills &lt; 50% of full tile count
- `npm run test:browser-perf:all` passes Chromium, Firefox, and WebKit

Evidence is regenerated by the Playwright suite; commit updates when baselines or fixture sizes change intentionally.
