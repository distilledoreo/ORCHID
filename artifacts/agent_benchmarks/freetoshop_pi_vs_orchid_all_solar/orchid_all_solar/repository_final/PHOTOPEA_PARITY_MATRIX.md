# Photopea Parity Matrix

This matrix tracks meaningful Photopea/Photoshop workflows against FreetoShop.
Executable code and tests are authoritative when documentation is stale.

**Maturity values:** Not started · Foundation only · Partially integrated ·
Functionally complete · Compatibility-hardened · Production-ready

No row may be marked complete based only on a button, type, interface, dialog,
or unit test. Functional completeness requires an ordinary end-to-end user
workflow. Compatibility-hardened requires representative files, malformed
inputs, undo, save/reopen, cross-browser, and regression evidence.
Production-ready additionally requires performance, accessibility, security,
documentation, and release evidence.

Last updated: 2026-07-16 (structured progressive cancellation recovery bounded tri-engine; imminent professional-editing queue recorded).

## How to update this matrix

1. Change maturity only with new implementation + tests + honest limitations.
2. Prefer advancing critical-path rows before shallow feature breadth.
3. After each milestone, record verification evidence (commands, counts, SHAs).
4. Keep `IMPLEMENTATION_ROADMAP.md` subsystem table aligned with this matrix.
