# Exploratory pilot — stopped

Stopped at a clean 42/128-case boundary (252 primary requests, no API errors). The earlier 39-case status was overtaken before the stop. All partial traces, ablations, quality replay, protocols, code, and private logs are preserved. This is not a final benchmark result, viability finding, or faithful engine-level SpecPrefill reproduction.

The text/API routing experiment did not preserve original model positions. Work has been redirected to a standalone token-ID/position-preserving SpecPrefill baseline before ORCHID storage, retrieval, or sufficiency gating are added incrementally. No production behavior changed.
